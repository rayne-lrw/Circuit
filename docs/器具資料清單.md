# 新增器具：資料清單與判斷規則

使用者上傳手冊、型錄或照片後，先照這份核對，再判斷能不能做，回報時寫清楚結論：
**資料齊全，可以做**、**有缺但可以推定後做（列出推定的地方）**、或 **缺什麼，不能做**。

## 一、每種器具都要有

| # | 資料 | 用途 | 通常在哪裡 |
|---|---|---|---|
| 1 | 型號清單 | 要建哪些型號、彼此差在哪（電流、點數、極數、線圈電壓） | 型錄訂購表（Product references／Catalog numbers） |
| 2 | 外形尺寸 | 寬×高×深 | 型錄或規格書的尺寸圖（Dimensions） |
| 3 | 端子排列（最重要） | 本體上每顆端子印什麼字、在哪個位置 | 端子排列圖、有標字的正面尺寸圖、正面照片（字要看得清楚）、安裝說明書的端子圖 |
| 4 | 接線圖 | 常開／常閉、共點、內部相通、線圈、輸入輸出 | 型錄或規格書的 Wiring／Schemes |

- 接線圖只畫連接關係，順序不一定等於實物位置，不能拿來代替第 3 項（例外見「三、可以推定」）。
- 同一個機框只要一張正面圖或照片；同框不同規格靠型號清單補齊。

## 二、依器具種類另外要的

| 種類 | 另外需要 |
|---|---|
| PLC 主機／模組 | I/O 點數、共點分組、位址規則（起始位址、每台佔幾點、擴充順序）、電源規格；連接器的針腳對照表 |
| 接觸器／繼電器 | 線圈電壓代碼表、輔助接點配置 |
| 熱電驛、輔助接點等附件 | 可搭配主體的對照表、安裝方式（下方插接／正面／側面）、裝上後的總尺寸或位置 |
| 斷路器 | 極數、N 極在哪一邊 |
| 轉接座、端子台 | 針腳 ↔ 端子對照、適用的 PLC 型號 |
| 正逆轉組等組合品 | 組合方式、原廠預先接好的線、互鎖方式、整組寬度 |
| 感測器 | 線色、輸出型式（NPN／PNP）、電源電壓 |
| 伺服、變頻器 | 主迴路與控制端子排列、連接器名稱 |

## 三、有缺時能不能做

### 缺了一定不做（等資料）
1. **不知道有哪些端子**（端子名稱或數量不確定）。
2. **端子位置有好幾種可能**，而且只有接線圖：例如 PLC 端子台、多排混合、共點夾在中間的排列。
3. **資料互相矛盾，而且會影響接線**：例如照片和接線圖對某個端子的位置說法不同（GVAU 的 D2）。
4. **附件的主體還沒做**：附件要等主體（例如 LRD33 要等 LC1D80／D95）。
5. **文件放錯**：說明書的型號和標題對不上，等正確的文件。

### 可以推定後做（說明裡標「推定」，回報時列出來）
1. **結構簡單、規則固定的排列**：每極上下對應的斷路器、保險絲座，接線圖順序和實物一致時可以直接用（例如 iC60N：每極 18 mm、上 1 3 5 7、下 2 4 6 8）。
2. **同系列其他型號有印字**：沒印的照同系列沿用（例如 LRD 系列的 97 98 95 96）。
3. **缺深度或部分尺寸**：用同系列、同機框推估。
4. **端子間距**：相對位置對就好，距離抓大概。
5. **同名端子是否內部相通**沒寫：照同系列慣例，標推定。
6. **本體沒印編號、但接線圖和實物排列能一一對上**：照接線圖，標推定。

### 照片或使用者的話優先
- 使用者提供的實物照片、或使用者明確說明（例如「LRD 系列都一樣」「LRD33 是不同系列」）優先於推定。
- 推定的地方，之後有照片就改成照實物。

## 四、常見問題（先檢查）
1. 照片太小、字看不清。
2. 合輯放錯檔（型號對不上）。
3. 只有接線圖，沒有正面圖或照片。
4. 同系列不同機框，每個機框都要一張正面圖或照片。
5. 同名端子要能看出內部是不是相通。
6. 附件要配主體，主體沒資料附件也做不了。

## 五、做的時候要有的（照目前的規則）
- 系列分組 `ser`（不重複寫廠牌）、資料來源（`VER`）、說明（來源、推定的地方）。
- 模擬動作資料（線圈、接點、斷路器、PLC 輸入輸出、跳脫等）。
- 附件用對應的安裝機制（下方插接、正面、側面、串接、插槽），可裝主體照對照表。
- 連接器收成一個接點（CN1），散線選針腳。
- 接點文字通過 `label-check`、資料通過 `tpl-data-check`、PLC 通過 `plc-sim-check`，再跑完整測試。
